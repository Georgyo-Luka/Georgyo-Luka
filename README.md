## Como penso qualidade

- **Teste o que importa primeiro:** a cobertura segue o risco, não a contagem de testes.
- **Teste rápido é teste que roda:** dados criados por API, execução paralela, feedback em minutos.
- **Qualidade se mede:** defeitos que escapam, testes instáveis e tempo de feedback são números, não impressões.
